Poker Timer

Веб-приложение для управления уровнями покерного турнира и отслеживания времени текущего уровня.

Проект создан в качестве учебного pet-project для практики HTML, CSS и JavaScript.

Возможности
Таймер текущего уровня,
Отображение Small Blind / Big Blind,
Переход к следующему уровню,
Возврат к предыдущему уровню,
Запуск и остановка таймера,
Настройка уровней турнира,
Добавление новых уровней,
Удаление уровней,
Сохранение настроек и текущего уровня в sessionStorage,
Автоматический переход на следующий уровень после окончания времени.

🛠️ Технологии
HTML5,
CSS,
JavaScript,
DOM API,
Web Storage API (sessionStorage)

🎯 Цель проекта

Основная цель проекта — практическое изучение JavaScript и работы с браузерным DOM API.

В процессе разработки были изучены и применены:

массивы объектов;
функции;
условия и циклы;
обработчики событий;
создание и изменение DOM-элементов;
работа с setInterval;
форматирование времени;
работа с sessionStorage;
динамическое изменение интерфейса;
разделение логики и представления;
базовый рефакторинг JavaScript-кода.

📌 Статус

Проект завершён как учебный pet-project.
Дальнейшее развитие проекта возможно, но текущая версия содержит основной необходимый функционал покерного таймера.
